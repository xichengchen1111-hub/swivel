# Swivel for Windows 测试版：安装说明

这是给朋友试用的**预览测试版**，还没有在很多电脑上验证过。请不要在存放重要文件的电脑上随意试用删除、移动类功能。

## 下载的文件

| 文件 | 用途 |
| --- | --- |
| `Swivel-Windows-Preview-test-certificate.cer` | 测试证书，第一次安装前导入一次 |
| `Swivel-Windows-…-win-x64.msix` | 普通 Intel／AMD 电脑用的安装包 |
| `Swivel-Windows-…-win-arm64.msix` | 骁龙等 ARM 电脑用的安装包 |
| `Swivel-Windows-…-win-x64.zip`／`…-win-arm64.zip` | 免安装版，解压即用，但其中 OCR（文字识别）和 PDF 页面工具不可用 |

不确定电脑是哪种：设置 → 系统 → 系统信息 → “系统类型”。写着 “x64” 选 x64，写着 “ARM” 选 arm64。

## 第一次安装（大约 2 分钟）

需要 Windows 11，并且有这台电脑的管理员权限。

1. **导入测试证书（只做一次）**
   1. 双击 `Swivel-Windows-Preview-test-certificate.cer`，点“安装证书…”。
   2. 存储位置选 **本地计算机**，点“下一步”（会要求管理员确认）。
   3. 选 **将所有的证书都放入下列存储**，点“浏览”，选 **受信任的人**，确定，然后一路“下一步”到“完成”。

   也可以用管理员身份打开 PowerShell，在文件所在文件夹运行：

   ```powershell
   Import-Certificate -FilePath .\Swivel-Windows-Preview-test-certificate.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople
   ```
2. **安装**：双击对应的 `.msix`，点“安装”。装好后在开始菜单里找 Swivel。

这张证书只用于本测试版的安装包，不能给网站或其他程序用。测试结束后可以删除：运行 `certlm.msc`，打开“受信任的人 → 证书”，删除 “Swivel Windows Preview”。卸载程序：设置 → 应用 → 已安装的应用 → Swivel → 卸载。

## 遇到问题怎么反馈

- 安装时报错：截图错误信息，或记下错误码（例如 0x800B0109 通常表示证书没有导入到“受信任的人”）。
- 使用时出错：截图弹出的提示，写下当时点了什么、用的什么文件（不用发文件本身，除非你愿意）。
- 一并告诉我们：Windows 版本（设置 → 系统 → 系统信息）、电脑是 x64 还是 ARM、显示缩放比例。

## 可以重点试的功能

开始菜单打开 Swivel 后，大多数工具默认关闭，需要先在 Settings 里打开对应开关。建议先试：

- 图片转换、裁剪、压缩（Wheel 默认开启）
- Archives：创建 ZIP，以及 **Extract ZIP…**（解压到压缩包旁的新文件夹）
- Move Files：移动和 **复制到文件夹**
- Text Capture：图片文字识别（只有 MSIX 安装版可用）
- PDF Pages：PDF 页面工具（只有 MSIX 安装版可用）
- Windows Doctor：各项只读检查
- Agent Tools (MCP)：如果装了 Claude Desktop，打开开关后点 **Install in Claude Desktop…**，在 Claude 里点“安装”（免安装版还要在扩展设置里选 Swivel.exe），然后可以让 Claude 检查、转换、压缩、改名或移动文件；写入前都会先给出计划，可撤销
