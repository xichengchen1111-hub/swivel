# Swivel for Windows — 0.83 preview

Windows 独立原生实现，使用 C# / .NET 10 / WPF / Win32。**这是多批功能扩展预览，尚未与 Mac 功能齐全对等，也未完成 Windows 实机验收。** 剩余进度见 [52项功能进度表](PROGRESS.md)，逐批记录见 [PORTING.md](PORTING.md)，差异见 [兼容调研](../reports/Windows与macOS兼容调研.md)，验收步骤见 [TESTING.md](TESTING.md)。Mac 源码、构建、设置和安装保持独立。

## 0.83 新增：复制到文件夹

启用 Move Files 后，页面上有 **Choose Files to Copy…**，也可把 **Copy to Folder…** 放进 Wheel／My Wheel。选 1–100 个文件和一个本地 NTFS 目标文件夹，确认完整列表后复制；原文件不动。副本使用原名，已被占用时依次改用 `名称 2`、`名称 3`…，绝不覆盖。

使用 Windows 自带的 CopyFile2：保留所有数据流（含下载警告 Web 标记）、属性和修改时间；创建时间为新，权限沿用目标文件夹。CopyFile2 创建副本时就记下其文件身份，复制后只核对这个对象，数据流名称和大小必须与原文件一致（不逐字节比较），不一致就通过该句柄删除；若名称已被其他应用移走或替换，Swivel 不碰它并提示。无法核对时副本仍列出并提醒检查。失败或取消立即停止，已完成的副本保留。

B06 仍为部分实现：跨卷移动、文件夹树复制／移动及会话撤销副本仍待做。固定52项仍22／24／4／2，普通剩余28。原生复制测试只交叉编译，真实 Windows 未执行。新动作存入 My Wheel 后旧版可能拒绝整份设置，降级前保留升级前备份。

## 0.88 新增：证件照

图片工具里新增 **ID Photo…**（单张）：一寸 295×413、二寸 413×579、护照 33×48 mm、美国签证 600×600 或自定义（像素或毫米，1–4000 像素/边），DPI 72–1200；底色白、蓝 #438EDB、红 #D9001B 或自选颜色；Zoom 与 Vertical Position 微调，右侧实时预览。保存为 JPEG（质量 95，写入所选 DPI），文件名 `名称 id.jpg`，放在原图旁、不覆盖。用 0.87 的定版 U²-Net 本机模型找出人物，用 Windows 自带的人脸检测（`Windows.Media.FaceAnalysis`）找脸；没有脸或超过一张脸都会拒绝。Windows 只给出脸的方框，没有 Mac 那样的五官定位，所以头顶由人物蒙版推算、下巴由方框估计，头部约占高度 70%、头顶离上边约 13%——请看预览再调 Zoom／Vertical Position。换底色时按“原像素 + (1−α)(新底色 − 估计旧底色)”处理，头发边缘不带旧底色；照片外的部分用底色补齐。仅供方便使用，正式用途请按发证机关要求检查。C10 由部分实现变为限定实现，固定 52 项为 23／26／1／2，普通剩余 27。真实照片、人脸检测在各 PC 上的可用性与打印尺寸仍待在真实 Windows 上验证。

## 0.87 新增：移除背景与背景虚化

图片工具里新增 **Remove Background**（主体保留、背景变透明，输出 `名称 cutout.png`）和 **Blur Background**（只虚化主体后面的背景，主体像素不变、不产生光晕，输出 `名称 blurred.png`），可批量，结果放在原图旁、不覆盖。使用用户批准的定版本地模型 U²-Net（权重 Apache-2.0，ONNX 由 rembg 导出、MIT），通过 Windows 自带的 Windows ML 在本机运行（有显卡用显卡，否则用处理器），不上传、不联网；模型随安装包提供，启动时核对大小与 SHA-256，不符就拒绝。模型在 320×320 上判断主体，复杂背景、细发丝、与背景颜色接近或不是“显著物体”的主体可能漏掉或带边；模型不太确定的淡背景（蒙版低于 16/255）也变为全透明，完全透明处的颜色会清空；边缘和模型拿不准的区域会半透明并保留原色（在 Owl 等测试照片上约 2–9% 像素），这些像素调成不透明就能看到原图，分享前请检查。完整安装包大约增加 176 MB。agent 工具（MCP）也可以调用这两个动作。证件照仍待做，C10 由待实现变为部分实现，固定 52 项为 22／27／1／2，普通剩余 28。

## 0.86 新增：Agent 工具（MCP）

在设置里打开 **Agent Tools (MCP)** 后，Claude Code、Claude Desktop、Codex 等本机 agent 可以通过 `Swivel.exe --mcp` 调用 Swivel（MSIX 安装后用别名 `swivel-preview.exe`）。只走标准输入/输出，不开端口、不联网、不显示窗口。设置页的 **Copy Agent Tools Setup** 复制三种主机的配置。工具：`list_actions`、`inspect_files`（只读）、`plan_action`、`apply_plan`、`undo`、`history`。写入只能先 plan 再 apply：计划一次性、1 小时内有效，输入文件的身份、大小或修改时间变了就拒绝；目前只开放在原图旁新建文件的转换（PNG/JPG/BMP/TIFF/GIF）、旋转、翻转和灰度，绝不覆盖。每次应用都记入历史（当前用户注册表），`undo` 先核对输出没被改动，再把它移到回收站；只在有回收站的本地固定盘上撤销，其他位置一律不动。OCR、读码、目标大小压缩、改名、移动和 MCPB 打包仍待做，G02 由待实现变为部分实现，固定 52 项为 22／26／2／2，普通剩余 28。真实 agent 主机尚未验证。

## 0.85 新增：资源管理器文件夹样式

在设置里打开 **Folder Style** 后，用 **Change Folder Style…** 选择 1–20 个本地文件夹，挑 10 种颜色之一并可加最多两个字符的标记（字母、数字、汉字或单色表情），预览后应用。Windows 的做法是在文件夹里放一个隐藏的 `desktop.ini` 和一个图标文件，并把文件夹设为“只读”（文件夹的只读不影响修改里面的文件）；Swivel 只在原来不是只读时才设，并把这一点记在自己的 `desktop.ini` 里。**Restore Default** 只删除这两个 Swivel 文件，只在 Swivel 设过时才清除只读。文件夹已有自己的 `desktop.ini`（比如“文档”“下载”等系统文件夹）时整个文件夹都不改动。不能选整个磁盘。资源管理器有时要刷新或稍等才显示新图标；OneDrive 等同步文件夹也会同步这两个文件。Mac 的材质、图片和彩色表情暂不提供。B09 由待实现变为部分实现，固定 52 项为 22／25／3／2，普通剩余仍 28。

## 0.84 新增：TAR／GZip 解压

同一动作改名为 **Extract Archive…**（My Wheel 里保存的 ID 不变），现在也接受 `.tar`、`.tar.gz`、`.tgz` 和单文件 `.gz`。规则与 ZIP 相同：先完整审查、显示全部路径，确认后写入新文件夹，不覆盖、逐文件暂存后独占出现并加 Web 标记。支持 POSIX ustar／pax 与 GNU 长文件名；拒绝硬链接／符号链接、设备、稀疏文件、分卷和未知类型。macOS 打包时附带的 `._` 属性文件（AppleDouble）不解压，对话框会写明数量。TAR 本身没有文件校验值：审查时为每个文件记录 CRC-32，解压时逐个核对；gzip 还核对尾部 CRC-32 与长度，截断、多段或附加数据都会拒绝。不还原所有者、权限和扩展属性。7z／RAR 解压、ZIP64、加密仍待做，B08 仍为部分实现，普通剩余 28 不变。

## 0.82 新增：安全解压普通 ZIP

启用 Archives 后，单选一个 `.zip` 可用 **Extract ZIP…**。先完整读取中央目录并逐项校验，再显示将创建的全部文件夹与文件路径、数量和解压后大小，确认后才写入。结果放在压缩包旁以它命名的新文件夹（已存在则依次用 `名称 2`、`名称 3`…），绝不复用或覆盖已有文件夹和文件。

支持 ZIP 2.0 的 Store／Deflate、完整普通目录树和空文件夹，最多 10,000 项、解压后 2 GB、32 层；需本地 NTFS。拒绝链接、设备等特殊项、加密、ZIP64、分卷、其他压缩方式、旧式非 Unicode 名称，以及 Windows 不安全名称（`..`、盘符、保留名、尾随点或空格、控制／格式字符）、忽略大小写或 Unicode 组合后重名、同名文件／文件夹、成员数据重叠和目录前后的多余数据。每个文件先写入隐藏的私有暂存文件，核对大小与 CRC-32 后才以最终名称独占出现。

每个文件都带 Web 标记：至少为 Internet（3）；压缩包本身是 Restricted（4）时保持 4，从不降级。保留压缩包里的修改时间；权限、属性、注释和其他数据不还原。解压不是事务：失败或取消时立即停止，已出现的文件留在新文件夹并报告数量，不自动删除。

B08 由待实现变为部分实现：TAR／GZip／7z／RAR 解压、ZIP64、加密 ZIP 与文件夹树归档仍待做。固定52项变为22限定实现／24部分／4待做／2平台差异，普通剩余仍28。真实 Windows 文件系统、界面、x64 与 ARM64 仍未执行；原生解压测试已加入 Windows 套件但只交叉编译。新动作存入 My Wheel 后旧版可能拒绝整份设置，降级前保留升级前备份。

## 0.81 新增：明确尝试平面二维码数据恢复

在 QR & Barcodes 中新增 **Recover Flat QR Text…**，选择一张本地图片后，尝试恢复有限的编码数据损坏。原有 **Read Flat QR Image…** 仍严格读取，不自动转为恢复模式；编码器输出和原图保持不变。支持版本1–40、L/M/Q/H及四个直角方向，仍要求精确四模块白边、均匀整数像素模块和完整定位／对齐／时序／格式／版本等结构。

只恢复每个纠错块的数据和校验字节，最多为该块校验字节数的一半；全部块及原文本语法都通过后才显示候选文字。原生结果窗明确显示改动字节与受影响块的数量，它们是与接受候选的差异，不能证明原始损坏量。超出纠错能力时可能得到另一个形式有效但内容错误的候选；成功或零改动都不验证真实性。透视、模糊、镜像、任意角度、边框及结构损坏仍不支持。

仅展示完整文字并提供明确复制，不打开链接、写图、保存库或发送。Windows Unicode文本剪贴板遇到U+0000会结束，两读取模式对含该字符的文本禁用Copy并说明原因，完整可见转义预览保留，不静默截断。取消等待读取清理，避免取消后迟到错误或窗口。

E05仍部分，固定52项22限定实现／23部分／5待做／2平台差异，普通剩余28；更广图片读取和其他条码继续待做。4,518,659项核心检查通过，原生套件仅交叉编译0警告／错误，独立复核见[TESTING](TESTING.md#081-验证记录)。真实Windows文件系统／剪贴板／界面／x64和ARM64仍未执行。最终0.81.0包状态以外置`BUILD-REPORT-0.81.0.json`为准。新动作存入My Wheel后旧版可能拒整份设置，降级前保留升级前备份。

## 0.80 新增：计划任务信息

Windows Doctor 的 Background Items 中新增 **Inspect Scheduled Task Metadata…**。明确点击后，只读取本机、当前程序权限可访问的非隐藏任务：名称、任务计划程序中的路径、原始状态值、Enabled 声明和上次结果的原始32位值。范围不等于“属于当前用户的任务”，状态和返回值也不能作为健康、可信或实际执行的判断。

任务路径默认隐藏，列表、选中详情、问题列表和两种复制共用显示开关；任务名称仍可能包含个人或软件信息，隐藏路径不等于匿名。没有任务运行、修改、禁用或删除按钮；不读取定义、脚本、动作、触发器或账户，不发送助手，也不保存快照。

最多根目录加4层、128个任务文件夹、1024次任务条目读取尝试、256Ki UTF-16文字预算和约15秒软时限；失败和未完成范围保持可见。系统调用和COM对象可能先分配或阻塞，因此不是系统内存或等待时间的硬上限。取消、关闭所属窗口、关闭Doctor及退出会等待线程和资源清理，可能超过软时限。

## 0.79 新增：明确启动的 Wheel 拖放手势

## 0.77 新增：移动文件与会话撤销

## 运行

目标 Windows 11 x64 / ARM64、普通用户权限。解压对应架构 ZIP 的整个文件夹，打开 `Swivel.exe`；包含微软 .NET Desktop Runtime，不需单独安装 SDK。开发包尚未正式签名，不能作为正式发行；不要为运行它关闭 Windows 系统防护。Windows 10 暂不列为已支持平台。

仅 Wheel 默认开启，其他工具在 Settings 各自启用。关闭主窗口会留在托盘，从 Quit Swivel 退出。界面支持英语、简中、繁中、日语。手动文件来自明确选择或拖入；另有明确启动的目录图片到达会话。文件列表有选中项时仅处理选中项，否则处理全部。

## 文件及平台边界

图片上限128 MiB、1600万像素、单边16384像素；像素规范化为8-bit SDR sRGB，常规编码器设置96 DPI（GIF不存DPI/ICC），应用 EXIF 方向并去除内嵌元数据。静态GIF只限完整画布/方形像素及明示扩展子集；拒绝多帧/APNG/动画GIF、HEIC/AVIF/WebP、HDR、高位深、CMYK。画布和拼图另有4000像素边长上限。所有格式与效果仍需 Windows 编解码和视觉验收。

输入限240字符以内的本地普通文件路径，不接受文件夹、UNC/映射网络盘、设备路径、备用数据流、链接或 junction 父目录、云占位文件。带 reparse point 的同步目录也可能被保守拒绝。原件在本地处理时持有只读句柄；改名使用专用 DELETE 句柄及身份检查；外部应用接收文件路径后自行负责读写。

临时输出原子创建，通过同一句柄不覆盖发布。取消等待当前系统编码/系统调用返回，清理尚未发布的输出，已完成项保留并显示；强制终止/断电可能留下 `.swivel-*.tmp`。没有启动扫描/自动删除。Optional 功能关闭时会取消所属操作，包括加载阶段。

本版没有自动启动、截图接管、剪贴板读取或 MCP。0.53助手仅在独立开启并完整预览后明确发送，基本Doctor脱敏解释及单次明确选择的自定义动作标签已接入；音频已有限定系统解码，PDF/OCR已有需MSIX身份的条件路径（普通ZIP不可用）。其他媒体/视频、完整PDF保真、更完整Doctor诊断、AI模型、拍照／透视模糊或结构损坏二维码读取、安全复制／跨卷移动／目录树／解压等仍见 PORTING；0.77仅补同卷NTFS普通文件移动及会话撤销。“尚未实现”不等于平台不兼容。

## 迁移文件来源

Mac 二维码库原文件是 `~/Library/Application Support/Swivel/QRCodes/library-v1.json`；复制该文件到 Windows 后使用 **Import Mac QR Library…**。Windows 只读取明确选中的本地副本，不扫描其他应用、修改源库或打开链接。

不兼容条目仍完整显示，确认只添加兼容项。备份只含配方或已保存二维码内容，不含API密钥；二维码内容是明文，应检查保存位置。导入不会改变任何工具开关，也不会替换已有配方或库文件。
