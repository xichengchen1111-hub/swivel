# 第二批媒体功能：扩展审查与修复

日期：2026-10-22。分支：`codex/media-batch2`。审查基线：六项功能完成后的 `cd29ad7`，并与 `media-editing` 区分新问题和原有问题。

主人要求扩大到六项以外，尤其检查安全。共分配 **12 个独立 agent 审查任务**，修复后另外复核私有临时存储和音频包络。没有安装应用、推送、合并、上传媒体、增加隐私权限、引入第三方代码或打包模型。

## 检查范围

| 任务 | 重点 |
| --- | --- |
| 1. 修复画笔 | 蒙版外像素、P3/高位深、远距离笔画、区域预算、取消 |
| 2. 字幕与转写 | SRT 不可信输入、行数、时间边界、本地识别、临时音频 |
| 3. 图片/视频放大 | 透明度、边界、尺寸、取消发布、系统接口能力、画质 |
| 4. 降噪 | 干净信号、噪声估计、声道、静音视频、取消 |
| 5. 证件照 | 透明前景、长软发丝、背景残色、异常尺寸、Vision 工作预算 |
| 6. 配乐闪避 | 长录音复杂度、左右声道、预览分析生命周期、音量曲线 |
| 7. 输出安全 | 独占写入、临时文件权限、回滚、链接、原文件保护 |
| 8. 媒体输入 | 安全 asset 入口、引用媒体、解析上限、时间戳与 PCM 扩张 |
| 9. 隐私与联网 | 首次下载同意、离线边界、权限、MCP、日志 |
| 10. 资源与取消 | 内存/磁盘预算、并行任务、清理、取消提交边界 |
| 11. 视频组合 | 剪切、变速、降噪、配乐、字幕、淡入淡出、音轨偏移 |
| 12. 测试缺口 | 负对照、最终文件检测、翻译、菜单位置、系统版本条件 |

每个结论区分静态代码证据、独立探针和正式回归；没有把未经实际复现的填盘、OOM 或同权限竞争升级成已证实的严重漏洞。原始 agent 报告与探针保存在忽略的 `build/agent-*.md`、`build/agent-*.log`。

## 已确认并修复

| 问题及触发条件 | 修复 | 验证 |
| --- | --- | --- |
| 私密源文件位于其他用户可遍历的目录时，自动生成的 CAF 可能以 0644 留在旁边 | 中间音频改放当前用户临时区内独立 0700 目录；成功、失败、取消都按拥有关系清理 | 0600 源文件、0700 父目录、取消/失败清理、重复清理、目录碰撞不删除他人文件 |
| 原有 24 小时/384 kHz/16 声道上限理论上允许约 2.12 TB PCM | 解码前计算含两份 PCM 的预算，每任务最多 16 GiB；并发预留、至少保留 1 GiB；4096 帧分块，持续检查空间，限制累计时间轴 | 极端参数在分配前拒绝；正常帧数/声道、预算和取消探针。没有实际填满磁盘 |
| SRT 通过符号链接的元数据大小绕过 2 MB 限制；空白分隔行解析异常 | `open` 不跟随链接、不阻塞特殊文件，`fstat` 验证普通文件，同一描述符最多读 2 MB+1；规范 BOM/换行并严格校验时间 | 精确上限/超限、链接/FIFO/目录、UTF-8、空白分隔、重叠时间 |
| 字幕超过三行时静默丢字 | 所有允许的行都参与排版；无法清楚容纳时导出报错；限制单条文本、行数、位图和缓存 | 第四行不同文本产生不同的实际像素；CJK 宽度及不可容纳输入 |
| 系统放大的半透明颜色重复乘 alpha；保存工作未接收父任务取消 | 分离不透明颜色和 alpha，归一化补足边缘颜色，最后只恢复一次 alpha；转发保存取消，发布前检查 | 多种 alpha、软边缘及错误算法负对照；确定性的保存取消、不产生半成品 |
| 放大一致性校正对有限图像边界采到黑色 | Lanczos 在缩放前延展边界，随后裁回精确尺寸 | 灰阶/定位点/边缘测试；五张本机照片比较 |
| 干净连续音没有可信噪声段时仍被重度消除；无原音轨视频打开降噪后导出失败 | 只在可信低能量、非窄带噪声样本下使用强消减；不确定时保守限制衰减；禁用无音轨控件，导出再防守一次 | 原噪声验收继续通过；多频、动态音量、紧裁语音、静音视频加配乐、取消/临时目录 |
| 修复画笔把整图变成 8 位 sRGB，影响未涂区域；相隔很远的小笔画扩大整个求解区域 | 只按供体索引复制原生像素；不相交区域分开处理；40 MP/320 MB 源数据及 2 MP 单区域预算 | P3/16 位、裁剪行跨度、未蒙版字节精确一致；8 MP 两笔独立探针约 104 MB RSS，原路径约 586 MB |
| 证件照透明度被忽略；长软发丝退回含旧背景的颜色 | 保留原 alpha，可信前景颜色通过有界多尺度传播；没有可信前景明确报错；工作长边最大 4096，Apply 可取消 | 4 种 alpha × 3 底色；2/5 px 宽、40/100 px 长发丝与错误混合负对照；预算和取消 |
| 配乐包络每个拐点扫描全部人声区间；备用检测只读第一声道；关闭功能仍分析 | 二分只查相邻区间；选有效能量声道；关闭配乐/闪避或原音静音时取消分析，完成回调校验代次 | 16,000 区间约 0.3 秒；独立 1,500 组、151,500 点与逐区间算法最坏差 7.94e-8；左右声道测试 |
| 原有视频音轨在淡入淡出相互重叠时，与画面和新配乐包络不同步 | 原音轨共享精确包络，保留用户实际淡入淡出长度；配乐自动尾淡出单独控制 | 短片、裁剪与 2× 变速的预览/导出音量参数匹配画面；这是相关的基线问题 |
| 集成测试仅检查视频存在音轨，不能证明最终闪避生效 | 读取最终 MP4 的 880 Hz 配乐频点，不只检查独立混音 | 最终视频人声期间的配乐下降约 12 dB；保留独立混音检查 |

本轮没有确认新增媒体上传、新隐私权限、MCP 暴露编辑器或绕过独占输出的路径。这是所列范围的结论，不能解释为所有输入或系统框架均已穷尽验证。原有通用路径祖先竞争等基线事项没有冒充成本轮新漏洞或已修复事项。

## 放大效果和 skill 学习

只读查看官方 skill-installer 的目录，没有找到直接适用于纯 Swift / Apple VideoToolbox 的超分辨率 skill。查看的 [xiaoer-upscale](https://github.com/Jane-xiaoer/claude-skill-xiaoer-upscale/blob/main/SKILL.md) 依赖 OpenCV 和下载模型，[image-upscaling](https://github.com/awesome-genmedia/skills/blob/main/.agents/skills/image-upscaling/SKILL.md) 使用云端 API；均不符合现有约束，没有安装或采用。参考了 [Trail of Bits differential-review](https://github.com/trailofbits/skills/blob/main/plugins/differential-review/skills/differential-review/SKILL.md) 的基线对照、攻击路径、可复现证据和测试覆盖方法，没有复制第三方源代码。

本机 SDK/系统只提供 normal/revision1、4× 模型，没有找到可切换的高质量档。保持系统模型，先修正确认的边界和 alpha 错误。五张本机照片在同一 RGB 测量方法下，修正边界后的 PSNR 均提高：

| 本机照片（128 → 512） | 修正前 RGB PSNR | 修正后 RGB PSNR |
| --- | --- | --- |
| Parrot | 28.7245 | 28.9698 |
| Eagle | 25.1331 | 25.1834 |
| Owl | 22.1402 | 22.5434 |
| Zebra | 19.8329 | 19.9813 |
| Flower | 22.1616 | 22.7498 |

这只是边界修复，不能声称恢复了本来缺失的细节。当前正式鹦鹉测试的 **RGBA PSNR** 为系统 30.2192 dB、普通放大 30.2326 dB，系统仍未高于 Lanczos。RGB 与 RGBA 数字不可直接横比。验收继续按主人先前决定保留基础效果、等待肉眼评审，不恢复“已优于 Lanczos”的说法。

另外试过保守锐化和四方向重建平均。锐化不能稳定提高五图保真度；四方向约需四次模型处理，部分指标提高但梯度下降，可能更软，因此都没有擅自设为默认。修复前后实际输出和同部位裁切对比保存在 `build/upscale-audit-*.png`，不额外锐化。

- 未安装应用，没有做真实 Finder 拖入、真实编辑窗口或主观试听；证件照仍需真人发丝、复杂背景和办理机构要求的人工验证。

- 系统超分辨率仍可能偏软，特别是 128 px 输入中的细小纹理。是否采用额外的更慢模式或突破无第三方模型约束，需要主人看实际效果后另行决定。
